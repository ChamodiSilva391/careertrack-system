# CareerTrack 🚀
### Smart Job Application & Interview Management System

CareerTrack is a modern web application built for job seekers, university graduates, and software engineers to seamlessly track job applications, multi-round technical interviews, and recruitment pipelines with real-time cloud synchronization.

---

## ✨ Features

- **Personal Job Application Tracker:** Track company, role, salary range, job post URLs, recruiter details, and notes.
- **Multi-Stage Kanban Pipeline:** Visual kanban board (Wishlist, Applied, Interviewing, Offered, Rejected) with stage transitions.
- **Interview Scheduler & Countdown:** Schedule multi-round interviews (HR, Technical, System Design, Final) with interview checklists and direct video meeting links.
- **Interactive Analytics:** Funnel conversion tracking and application status breakdowns.
- **Multi-User Cloud Sync:** Backed by Google Firebase Authentication & Firestore NoSQL DB with per-user data isolation.
- **Data Export:** Instant export of applications to CSV (Excel) and JSON.

---

## 🛠️ Tech Stack

- **Frontend:** React 19, Vite 8, Tailwind CSS
- **Backend / Database:** Google Firebase (Firestore DB & Firebase Auth)
- **Icons & Charts:** Lucide React, Recharts
- **Languages:** JavaScript (ES6+), HTML5, CSS3

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/ChamodiSilva391/careertrack.git
cd careertrack
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open `http://localhost:5180` in your browser.
